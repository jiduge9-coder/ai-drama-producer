# ai-drama-producer — AI 短剧制片班底技能

> 把一个剧本变成**可直接拿去生成的全套物料**：剧本拆解 → 看点设计 → 角色一致性档案 →
> 资产图锚点 → 分镜表 → 逐镜首帧图提示词 → 逐镜视频提示词（模型无关七段式核心 + 平台
> 适配注记 + 英文镜像）→ AI 配音方案 → 剪辑清单。内建深挖制提问协议、四层质量自检、
> 合规硬闸门和通用失败模式库。

## 它是什么（30 秒版）

这不是"一键成片"工具——一键成片的尽头是模板化同质化。这是一个**制片班底**：
你是制片人，技能按影视工业前期流程干活（剧本拆解表 → 资产编号 → 分镜 → 物料 →
QC），每个关卡先对齐再产出，每条提示词过三通道审查（合规 / 反模式 / 人工清单），
每一分生成额度都有预算门。

**四个差异化设计**（对应 AI 短剧被诟病最多的四个问题）：

| 行业痛点 | 本技能的对策 |
|---|---|
| 剧情降智、套路扎堆 | 深挖制提问 + 对齐优先落盘在后：文件是共识的记录，不是沟通的替代 |
| 盗脸/融声/版权乱象（已被官媒点名） | Gate 0 红线清单 + 三通道审查的合规位一票否决 |
| "AI味"重（油脸/乱码/口型翻车） | 18 条通用失败模式库 + 文字归首帧双轨制 + 质感锁 |
| 烧钱无底洞 | 额度预算门 + 生产硬闸门（确认绑定版本指纹）+ 每镜备选写法 |

## 快速开始

把本目录放进 agent 技能目录（如 `~/.agents/skills/ai-drama-producer/`），然后在任意
会话里丢给 agent 一句话：

```
这是我的剧本（粘贴/给路径），出AI短剧物料
```

或只说需求：`帮我分析这张图的风格`（风格反推）、`这个镜头生成出来人物很油怎么办`（QC 修复）。

Agent 会按管线走：**Gate 0 立项提问（含红线四查）→ Gate 1 拆解分镜（你确认）→
资产锚点包（你确认）→ 额度预算门报价 → 物料包 → 你拿去生成 → 带症状回来修**。

### 项目级校验

每个阶段收尾时可跑校验器（零依赖）：

```bash
python scripts/validate_project.py <项目目录> --gate 1          # 拆解分镜阶段：五件套+红线清单+分镜表列完整性+镜号唯一性
python scripts/validate_project.py <项目目录> --gate 2 --multi  # 物料包阶段：追加锚点/提示词/声音/剪辑/QC 日志
```

## 设计原则

1. **对齐优先，落盘在后**——写完就可能因意见分歧被重写的文件，写早了。
2. **平台无关**——提示词永远是"模型无关核心 + 适配注记 + 英文镜像"，不在任何单一平台押注。
3. **经验可沉淀**——每次 QC 的新失败模式写回 lessons.md，技能随使用变强。
4. **零硬依赖**——本机装有反模式引擎/导演类技能则自动借用，没有则内置人工清单兜底。
5. **个人偏好不内置**——预算/画幅/工具口味在 Gate 0 现场问，按项目存档。

## 适用与不适用

- ✅ AI 短剧/微短剧/竖屏剧情片/品牌故事片的物料生产；风格反推；生成失败修复
- ❌ 剧本续写打磨（交给剧本类技能，本技能从成稿开始）；剪辑成片的替代（只出清单）；
  不替代任何生成平台本身

## 合规承诺

生成前强制过肖像权/版权/内容三查（P0 一票否决），红线源头登记在项目档案。
本技能不生成真实人物肖像内容，不处理受保护 IP 角色的直接还原。
