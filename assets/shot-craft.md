# 镜头趣味性规范（shot-craft.md）

> 解决"分镜每镜都对、连起来却平"的问题。分镜表做完后，用本文件逐镜过一遍；
> 写每个镜头提示词前，先看本镜头用了下面哪几招。**平的分镜不是镜头错了，是镜头之间没有化学反应。**

## 一、一镜一问（基础准入）

每个镜头入表前回答：**观众看完这一镜，脑子里多出了什么问题或什么信息？**
- 加深问题的镜头 ≥ 给答案的镜头（钩子密度）
- 既不加深问题也不给信息的镜头 → 删（省额度）
- 连续两镜回答同一个问题 → 合并

## 二、信息分层递进（重复与变异）

同一元素（道具/角色/场景）在片内多次出现时，**每次必须多给一层信息，并至少变一个视觉参数**：

```
报站屏第一次：12分钟（建立常态）
报站屏第二次：41:00 还在跳（打破常态）
报站屏第三次：下一站 起点（改写规则）
```

重复建立预期，变异打破预期。三次都是同一信息=浪费额度。

## 三、镜头间的化学反应（库勒肖夫效应）

**相邻两镜组合出的语义 > 单镜语义。** 排镜头顺序时问：这两镜挨在一起，观众会"读"出什么第三层意思？
- 特写车票 → 切乘客低头 = "他们认得这张票"（顺序反过来="他害怕这张票"）
- 排完分镜表，把相邻镜头两两连线过一遍，把组合语义写在"衔接"列里
- 语义错了就换顺序——改顺序零成本，改内容烧额度

## 四、视点策略（别总用主角视点）

一场戏里至少切换一次视点，被注视感、悬念感都来自视点差：
- 主角视点（我们看到他所见）
- 观察者视点（我们看他被看——群像转头看他/老者眼里映着金光）
- 物件视点（报站屏/车票的"凝视"——特写静止就是物件在看他）

## 五、运动的方向语义

运镜不是装饰，是叙事词。每个镜头运动都要能翻译成人话：
| 运动 | 人话 |
|---|---|
| 极缓推近 | 真相在逼近/情绪在聚焦 |
| 拉远 | 人变小了/被世界抛下 |
| 匀速横移 | 命运在滑行/时间在流逝 |
| 静止 | 屏息/对峙/等待爆发 |
| 手持轻晃 | 失控感 |

一镜内禁止两种翻译（运动叠加红线）；全片"静止"镜头占比高是克制叙事的标志，不是缺点。

## 六、前景与框架（竖屏刚需）

竖屏 9:16 纵深浅，用**前景遮挡**造纵深和偷窥感：车门缝里看人、扶手栏杆切前景、
椅背半遮、人群肩后过肩。每 3-4 镜安排一个带前景框架的镜头。
**前提是首帧图提示词里写明前景层**（L2 空间段必须有前/中/后三层，不能只有主体）。

## 七、声音先行（声音桥）

下一场的关键声音提前 1-2 秒进入本场（广播底噪/轨道异响/心跳）——观众耳朵先到，
眼睛后到，转场就"顺"。写进分镜表声音列：`S1-07 起铺广播底噪，S1-15 广播词入`。

## 八、光与色的递进（色彩脚本做钩子）

让一种光/色承担剧情推进（如"暖金=命运入侵"）：它每多侵入一寸=剧情推进一步，
观众不需要台词就能读进度条。场景档案里必须写清这条递进的**物理载体**
（车票金光→脸上金光→门外金色）。

## 九、定格与留白（问号要给时长）

关键问号画面给足时长（4-8s），让问号自己长出来——断章镜头宁可信息少也要停得住。
爽点后的反应镜头（眼神变狠）给 4s 起，别急着切。

## 十、主动权时刻（爽感的核心机制）

**"被选中"不如"自己抓住"。** 关键转折设计成主角的主动动作（攥紧/抓住/迈出一步），
命运递过来的东西要让他伸手接——观众爽的是 agency，不是特效。
每集至少一个主动权时刻，放在情绪爆点位。

## 自检清单（分镜表交付前过一遍）

- [ ] 每镜能回答"一镜一问"，无废镜
- [ ] 重复元素都有信息分层，无三次同信息
- [ ] 相邻镜头两两连线，组合语义成立且写在衔接列
- [ ] 全片视点 ≥2 种切换
- [ ] 每个运镜能翻译成一句人话，无两种翻译叠加
- [ ] 每 3-4 镜有一个前景框架镜头
- [ ] 声音桥标在分镜表声音列
- [ ] 色彩递进有物理载体且逐镜可查
- [ ] 断章定格 ≥4s
- [ ] 本集有 1 个主动权时刻
