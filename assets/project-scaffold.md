# 物料包目录与模板（project-scaffold.md）

> 项目目录建在用户当前工作区下，以剧名命名；用户指定位置则从其指定。
> 每个文件交付时套用下面的骨架，保持跨项目结构一致（用户换剧不用重新学习）。

```
<剧名>/
  00-project-brief.md        项目档案（Gate 0 产出，个人偏好存档处）
  01-breakdown.md            剧本拆解
  02-hooks.md                看点四件套落位表 + 悬念账本
  03-continuity-bible.md     角色/场景/道具档案 + 身份不变式
  04-shot-list.md            分镜表（含衔接列：组合语义+声音桥）
  05-series-arc.md           全季架构（多集剧：世界观真相/反转分层/悬念回收表/断章咬合）
  assets-anchors/            资产图锚点包
    characters/              角色定妆图（+按需扩展图）
    locations/               场景锚点图
    props/                   道具锚点图
    style-lock.md            画面风格锁（文字块+可选参考图）
  05-keyframes/              逐镜首帧图提示词
  06-video-prompts/          逐镜视频提示词（七段式+适配注记+英文镜像）
  07-sound-plan.md           配音文案+音效+BGM
  08-edit-plan.md            剪辑清单（剪映口径）+文字后期兜底清单
  09-qc-log.md               生成统计与失败记录（额度预算门的依据）
```

## 00-project-brief.md 骨架

```markdown
# 《剧名》项目档案
- 题材/基调 / 集数 / 单集时长：
- 平台生态：（聚合平台/单平台，所用模型系）
- 画幅策略：主版+安全区，逐场景可变
- 预算纪律：单集镜头上限 / 每镜重试上限 / 生成路径（图生视频优先）
- 质感基调：L1+L6 缺省组合（多时空线各自标记）
- 红线清单：肖像权□ 版权□ 内容敏感□（命中项+替身方案；Gate 0 立项必填）
- 声音：配音工具/音色要求/声音标识
- 剪辑：工具口径
- 假设记录：（未确认项及其状态，被推翻则更新）
```

## 04-shot-list.md 骨架

```markdown
| 镜号 | 时长 | 景别 | 运镜 | 走位(起→止) | 光线 | 资产引用 | 类型 | 文字内容 | 备选写法 | 衔接 | 断章 |
资产引用列填编号（A01/S03/P02/E01），不复述描述。
类型：普通/文字镜头/对白镜头/高危运动镜头；文字镜头必填文字内容列。
备选列：每镜一条降级写法（更近/更静/更简/改画外音/改反应镜头/剪辑补救）——
  生成失败时按备选重试，同一写法硬磕 3 次不如果断换备选（成本阶梯见 qc-loop）。
衔接列填组合语义+声音桥（转场目录：物体接口/遮罩匹配/声音先入/瞳孔转场等，T1-T7 编号管理）。
按场打色域标签（如暗红域=威胁、银蓝域=情感，双色=冲突高潮）——色彩脚本进分镜维度。
表尾统计：总镜头数、各类型计数（额度预算门输入）。
```

## 07-sound-plan.md 骨架

```markdown
## 配音文案（AI配音，每片段单一说话人）
| 镜号 | 角色 | 台词（含配音标点：逗号=小停顿/句号=收住/省略号=卡住/破折号=转折） |
## 音色要求（工具无关）
| 角色 | 性别年龄感 | 音色气质 | 语速 | 情感基调 |
## 声音层与视觉节拍对齐
| 镜号 | 环境音 | 音效点 | 音乐 | 台词/画外 | 节拍对齐（声音落在画面第几秒的哪个动作上） |
（每条声音标注它对齐的画面动作时间点——声音跟着画面节拍走，不是铺满即完事）
## BGM：卡点建议 + 声音标识（片头沿用）
```

## 08-edit-plan.md 骨架（剪映专业版口径）

```markdown
## 时间线：镜号顺序/入出点/转场/卡点
## 字幕：台词字幕轨（剪映文本轨，样式/安全区）
## 文字后期兜底清单：首帧方案未覆盖的文字（来源镜号+内容+出现时长）
## 发布差异：抖音版/B站版剪辑与封面差异
```

## 09-qc-log.md 骨架（失败统计反哺的数据源）

```markdown
| 镜号 | 生成次数 | 首图/视频 | 结果(✅/❌原因代码) | 返修动作 | 额度消耗 |
周期性统计：最烧钱环节 Top3 → 追加进 lessons.md；高通过率写法 → 提升为模板默认值。
```

## 视觉规格锁（Gate 1 产出，进 00-brief 或 03 档案）

```
模拟摄影机：焦段/画幅/帧率/景深策略
肤色策略：自然纹理/哑光/禁磨皮
运镜禁忌：本剧禁用的运动（防风格漂移）
光线逻辑：主光方向/色温域/对比度域
调色：主色调/记忆色/饱和度域
```
