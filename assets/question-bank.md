# 深挖制提问题库（question-bank.md）

> 用法：每个关卡进入前，从对应小节挑题问用户。选择题优先（2-4 选项+Other），
> 一次最多 4 题，分轮进行；用户没答的标假设继续做并在交付物开头集中列出"本次假设"。
> 个人偏好的确认结果写进该项目 `00-project-brief.md`，下次同项目先问"沿用上次配置吗"。
> **技能不内置任何个人偏好**——以下"推荐"选项是通用最佳实践，不是硬编码。

## 对齐题库（每个关卡落盘前先过；文件是共识的记录，不是沟通的替代）

### 品味校准（项目首次对齐必问）
1. 有没有"就是这个味"的参考作品？（网文/短剧/电影/游戏都可——参考名只是索引，
   要追问"它哪里让你爽"，拆成可执行维度）
2. "差点意思"是哪一层差？（世界观奇观浓度 / 爽感落差 / 主角魅力 / 节奏刺激度 /
   情绪余味——多选+用户用自己的话补充）
3. 反向排除：绝对不要出现的东西？（某些梗/某种人设/某种结局倾向——记入红线）

### 方向分歧（改向时必问）
4. 新方向跟已有物料的兼容性：哪些文件不用动、哪些要动、哪些作废？（先剖析再动手）
5. 两三个候选方案并排摆（各一句话+一个代表性画面），让用户挑而不是让用户猜
6. 被否的方向记进 00-brief 版本记录（防重复提议，也防日后用户"还是原来那个好"时有据可查）
7. **可视伴侣**：当候选方案的差异是视觉性的（风格帧并排/分镜方案对比/画幅对比）时，
   主动提出"我可以在浏览器里做并排 mockup 给你挑"（参考 superpowers 的 visual
   companion 模式）——用户同意再开，纯文字能说清的不用

### 每集开写前的对齐
7. 本集在季结构里承担什么（埋什么/爆什么/收什么）——用户认不认这个分工？
8. 本集的"一个记忆点"是什么？（用户 24 小时后还记得的那个画面/那句台词）

## Gate 0 · 项目画像（首次必问，同项目后续跳过）

### 0.1 平台生态
"你在哪些平台/工具生成视频？"（多选）
- 聚合平台（小云雀等，一家平台多家模型，常有免费积分）→ 提示词按模型无关核心出，附主流模型适配注记
- 即梦/豆包系 → 适配注记对齐 Seedance
- 可灵 / 海螺 / Vidu / Veo·Sora·Runway → 对应适配注记 + 英文镜像
- 还没定 → 按聚合平台口径出，物料通用性最高

### 0.2 画幅与平台投放
- 9:16 竖屏（抖音/快手/红果）为主
- 16:9 横屏（B站/YouTube）为主
- 双画幅都要 → 问清是"竖主+横版混剪"还是"两套独立规划"（生成量差一倍）
- 未定 → 建议 9:16 主版+16:9 安全区构图，逐场景再确认

### 0.3 预算纪律
- 严格预算制：单集 ≤40 镜、每镜重试 ≤2 次、图生视频优先（省额度，推荐起点）
- 分级预算：钩子/断章/情感锚镜头双倍重试，过场镜头严控
- 质量优先：不设硬限，每关卡报实际用量
- 追问：单集目标时长？（60-90s 高概念 / 2-3 分钟 / 10 分钟长集）

### 0.4 题材与尺度
- 题材基调确认（情感/悬疑/科幻/古装/ comedy…→ 影响质感基调表选型）
- 内容安全：有无名人脸/品牌标/敏感设定？（生成前安全校验的输入）

### 0.5 声音与剪辑工具
- 台词：AI 配音平台 / 剪映TTS / 真人录音 / 声音方案不锁工具按角色列要求
- 剪辑：剪映专业版为主（默认）/ AE 参与文字特效 / 其他
- 有无本剧"声音标识"需求（如固定片头音效）？

### 0.6 叙事形态（多集剧才问）
- 单集断章策略：悬崖尾 / 反转尾 / 情绪尾
- 有无片头/片尾固定模板需求

## Gate 1 · 方向确认（拆解产出后）

1. 镜头总数 = 额度预算基数，超预算时砍哪类镜头？（问优先级：钩子>情感锚>过场）
2. 角色视觉锚点认不认可？（档案的不变式字符串+不完美锚点，用户可能直接改设定）
3. 钩子位置认不认可？（四件套落位 + 悬念账本）
4. 断章位置和断章方式？
5. 有无必须保留/必须删除的场面？（用户对剧本的执念点）
6. 多时空线（回忆/推演/幻境）的质感区分方案认不认可？

## 资产图锚点确认

1. 角色定妆图：默认全身白底 1 张/角色。哪些角色需要**现在就**扩展三视图/表情图？
   （其余到具体场景需要时再出，避免白烧额度）
2. 场景锚点图覆盖哪些场景？（只做主场景，过场用文字锁定）
3. 有参考图要反推画面风格锁吗？（有 → 走 style-reverse；无 → 文字定义风格锁）
4. 风格方向定稿了吗？（未定 → 先做风格测试：同一场景出 A/B 两版对比，
   定稿后写死美学介质并标废旧版物料）
5. 资产编号规则沿用项目已有的（A角色/S场景/P道具/E特效/V音频）还是新立？

## Gate 2 · 物料包确认

1. **额度预算门报价单**：镜头数 ×（首图 1 次 + 视频 1 次）× 重试上限 = 最坏情况额度。
   按用户平台单价折算。确认后才开始出物料。
2. 文字镜头清单：哪些镜头的画面内文字走"首帧承载"？哪些字幕类文字留后期？
3. 配音音色要求：每角色性别/年龄感/音色气质/语速/情感（工具无关描述，用户拿去任何
   AI 配音平台都能选型）。

## 逐场景生成时再确认（用户回来要某场景物料时必过）

> 用户明确说过：到具体场景时他的考虑可能和项目初期不一样。所以每批场景物料产出前问：

1. 这批场景用什么平台/模型生成？（可能和项目主平台不同）
2. 这批场景的画幅？（默认沿用项目设定，但允许单场景横版）
3. 这批场景的时长档位对齐哪个口径？
4. 该场景角色要不要临时扩展定妆图（三视图/表情/换装）？
5. 该场景有无新增文字内容？（决定文字镜头走首帧还是后期）
6. 该场景的质感标记沿用还是调整？

## 假设标注机制

用户跳过的问题，在交付物开头统一列：

```
## 本次假设（未确认项，可随时推翻）
- 平台口径：按聚合平台通用处理（你未指定）
- 画幅：9:16 主版（沿用项目设定）
- …
```

推翻某个假设 → 只重做受影响的文件，不全量重做。
