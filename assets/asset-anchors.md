# 资产图锚点体系（asset-anchors.md）

> 核心理念（用户提出并验证）：**资产图 ≠ 镜头生成**。资产图是后续所有画面生成的
> 参考锚——先把"不变的锚"备好，镜头物料引用锚，而不是每个镜头从零描述。
> 锚点做得好，角色不换脸、场景不漂移、风格不发散；锚点做多了白烧额度，所以默认最小集。

## 一、四类锚点

### 1. 角色定妆图（每角色 1 张，默认最小集）

**默认产出：全身白底定妆图 1 张/角色。**

为什么是全身白底单图（而不是九宫格）：
- 九宫格拼图每个格子分辨率低，细节表达不出来（实测教训）；
- 三视图/表情图/换装图等到**具体场景需要时**再扩展——多数平台（如小云雀）支持
  从白底全身图直接扩展出预设三视图、表情九宫格，即用即出，不预付额度。

**白底定妆图提示词模板**（中文，图生图/文生图通用）：

```
纯白色无缝背景，摄影棚三灯布光（主光4500K柔和顶侧光+轮廓光+补光），
85mm镜头，f/5.6，全身像，人物居中占画面高度70%，双脚完整入画，
站姿自然放松，正视镜头。
〔身份不变式字符串：性别年龄/脸型/眼形/发型发色/肤色质感（自然皮肤纹理、
可见毛孔、哑光肤色）+2个不完美锚点/体型/全套服装鞋袜配饰，一次写全〕
自然皮肤质感，无磨皮，无油光，无蜡像感。
画面中不出现：文字、水印、道具、阴影投射、背景装饰。
```

摄影参数缺省值：85mm、f/4-5.6、5500K、三灯、面部/人物占比 60-70%、3:4 竖构图。
用户平台不支持参数写法就删参数保留描述。

**角色档案字段骨架**（写进 03-continuity-bible.md，与定妆图互相锁定）：

```
不可变特征（跨所有镜头逐字复制）：脸型/眼形/眼神/肤色/鼻/唇/特殊标记（痣疤纹身）/
发型发色基线/体型
可变状态（按镜头标注）：眉/眼/唇状态、表情（七态：中性/喜悦/愤怒/悲伤/恐惧/惊讶/冷漠，
  每态按眉-眼-唇-整体四行描述）、姿态
服装锁：本集/本线固定穿搭（换装=新服装锁，单独编号）
2 个不完美锚点：如"左眉尾小疤""指甲修剪不齐"——跨镜头身份稳定器
语言指纹（对白一致性，源自人物圣经方法论）：句式长短/用词域/口头禅/回避的表达/
  标志性锚点句——写进 07-sound-plan.md 的配音指导
红线检查（角色级铁律）：如"该角色永不说某类词/某道具只在特定条件下出现"——
  每集开写前对照，违规必改
弧线状态表：逐集标注角色状态（多集剧用）
```

### 1b. 角色卡防丑体系（v7 实战验证，多视图角色卡必用）

三重防线，防的是**结构性畸形**（脸歪眼斜/六指鸡爪/头大身短/多余人物），不是美学丑：

1. **正向锚（可观测验证的写法）**：面部五官比例对称、头肩比数值（1:2.5~1:3.5）、
   双手五指清晰；五官写成**完整可枚举清单**（脸型+肤色肤质+鼻型+唇形+眉形+眼型+
   身高+体型全量写死，不给模型自由发挥空间）
2. **CHARACTER CORE 单一事实源**：造型只在开头写一次，各视图段只写角度/构图
   （重复完整描述=模型生成四个不同角色，见 lessons.md #14）
3. **防丑负向包**：`面部畸形、五官不对称、多余手指、手指畸形、解剖错误、
   头大身短、比例失调、多余人物`（英文卡：deformed face / asymmetrical eyes /
   extra fingers / bad anatomy / big head / short legs / distorted proportions /
   different characters）

**验收四条**（生成后必查，不过就重摇或加对应负向词）：
- [ ] 所有格子是同一个角色？
- [ ] 脸歪没歪、五官对称吗？
- [ ] 手指几根、形态正常吗？
- [ ] 头肩比在 1:2.5~1:3.5 内吗？

### 1c. 风格测试（风格定稿前必做）

同一场景出 A/B 两版对比（如风格A vs 风格B、或厚涂 vs 写实CGI），用户选定后在画面
风格锁里写死美学介质，旧风格物料标 `DEPRECATED`。中途换风格=回资产锚点层重做
（lessons.md #17）。

### 2. 场景锚点图（每个主场景 1 张）

锁定：空间结构（远中前景三层）、光源方向与色温、材质基调、时间氛围。
提示词模板 = 定妆图模板的背景版（人物段换成空间段）。过场场景不配锚图，用
03 档案里的文字锁定（省额度）。

### 3. 道具锚点图（仅关键剧情道具）

触发条件：该道具出现在特写镜头、或承担剧情功能（信物/证据/Mcguffin）。
白底或场景内特写皆可，锁形态/材质/磨损细节。

### 4. 画面风格锁参考图（0-1 张，可选）

用户有参考图 → 走 `style-reverse.md` 反推**画面风格锁**提示词块，同时可选生成一张
"风格锚定图"作为后续首帧的风格参考。
用户无参考图 → 用文字定义风格锁（L1+L6 组合），不出图。

## 二、资产编号引用制（镜头层引用资产层，不复述）

所有资产编号入库（源自一个 8 集悬疑剧实战项目的资产体系），分镜表和提示词**引用编号**而非重复描述：

| 类 | 编号前缀 | 内容 |
|---|---|---|
| 角色（含群演） | A01、A02… | 定妆图+不变式字符串 |
| 场景 | S01、S02… | 场景锚点图+空间不变式 |
| 道具 | P01、P02… | 道具锚点图+形态锁 |
| 特效/视觉符号 | E01、E02… | 特效规则资产化（如"义眼红光三级""数据流"——统一写法防漂移） |
| 音频 | V01、V02… | 声音资产（如固定机械音色=全剧唯一不变声音资产） |

每条资产含：编号、出场场次索引、视觉描述、可复制的生成提示词。
文件命名沿用项目已有规则（如 `E03_S07_镜07_v2.mp4`）。

**三条单帧路径职责分离**（防同一张图承担过多职责）：
- 风格测试帧（lookdev）：只验风格方向
- 资产参考板（定妆/场景/道具锚点）：锁定可复用事实
- 分镜关键帧：只投影本镜头的起始状态
一张图只能服务一条路径；分镜关键帧直接拿定妆图当首帧=构图失控。

## 三、锚点与镜头物料的引用关系

```
角色定妆图 ──@绑定──► 所有含人物镜头的首帧图提示词与视频提示词
场景锚点图 ──@绑定/参考──► 该场景全部镜头的首帧图提示词
道具锚点图 ──@绑定──► 该道具特写镜头
画面风格锁 ──逐字复制──► 全项目每条提示词的 L1/L6 段
```

引用规则：
- 锚点生成通过后**锁定**，后续镜头不得改写锚点描述（要改 → 回档案改，全项目同步）
- 每条镜头提示词的参考图绑定行按用户当前平台语法写
  （Seedance 系 `@定妆图 作为主角`；其他平台按其参考图功能替换）

## 四、扩展时机决策表（到具体场景再问用户）

| 信号 | 扩展动作 |
|---|---|
| 场景有角色的近距离表情戏 | 出该角色表情图（或用平台表情预设功能） |
| 角色转身/背面镜头多 | 出三视图（背/侧） |
| 角色换装进新时空线 | 新服装锁 + 换装定妆图 |
| 场景需多角度反复使用 | 出第二张场景锚点（反打方向） |
| 纯过场/单次镜头 | 不扩展，文字锁定 |

扩展前过一遍额度意识：这张图会被 ≥3 个镜头引用才值得出。

## 五、资产图自身 QC

- 定妆图先过双通道审查再交给用户（油脸检查、白底纯净度、占比、无文字）
- **图-提示词逐项核对**（源自实战项目的核对报告实践）：用视觉能力逐张读图，
  与提示词逐项对照打分——多出的元素（道具入侵/多余人物）、画风串味（3D 混入手绘体系）、
  水印，逐项判"重做/微调/通过"，裁决记入 QC 日志
- 定妆图不合格不进入镜头物料——它是全项目一致性的地基，地基歪了全歪
- 用户对定妆图满意后，把最终图文件名/链接登记进 03-continuity-bible.md
