# 画面风格反推规格（Style Reverse）

> 触发：用户给一张参考图/视频，要"分析风格 / 照这个感觉出图 / 反推提示词"。
> 底子来自反编译规格（图片 7 维度 + 视频 6 维度），升级点：产出可复用的「画面风格锁」
> 提示词块。（命名注意：叫"画面风格锁"而非"风格锁"，与剧本类技能里的文字语言
> "风格锁"区分，防止跨技能字段污染。）

## 输入

一张参考图（或整段参考视频）。多张图时：逐张分析 → 求公共不变式 →
差异点单独列出让用户选主导。视频输入走第七节增量维度。

## 七维度分析（逐维度写，别跳）

| 维度 | 看什么 | 输出 |
|---|---|---|
| F-SUBJ 主体 | 人物/物体的形态、材质、比例、表情 | 一句自然语言主体描述 |
| F-STYL 风格 | 主风格判定：写实摄影/二次元/油画/水彩/商业插画/概念设计/像素/3D渲染 + 混合比例 | 主风格 + 混合风格 |
| F-ENV 环境 | 室内外、自然/人工、场景类型、背景密度 | 一句环境描述 |
| F-COMP 构图 | 景别（特写-全景）+ 视角（平/俯/仰）+ 主体位置 | 构图类型 |
| F-LIGHT 光影 | 光源方向、光质（软/硬/逆/轮廓/体积）、色温 | 光源方向 + 光质 |
| F-COLOR 配色 | 主色调、辅助色、对比策略、饱和度、色块占比 | 配色描述 |
| F-TECH 技术 | 颗粒/噪点/笔触/渲染特征/后期痕迹（胶片颗粒、HDR、AI特征） | 技术特征列表 |

风格判定要落到"训练数据锚点"：能对应到具体美学流派/年代/媒介就说
（如"90年代港片调色""胶片 bleach bypass""日式赛璐璐"），比空形容词有用得多。

## 输出三件套（缺一不可）

### 1. 风格判定报告
七维度逐项 + 一句话总评（"这是 XX 风格，靠 XX 光效和 XX 配色撑住辨识度"）。

### 2. 画面风格锁提示词块（核心交付物）

一段 30-60 字的**风格不变式**，之后本项目每条图片/视频提示词把它逐字复制进
L1（技术）和 L6（风格）段。要求：只含风格维度（构图/光影/配色/质感/媒介），
**不含主体和场景**——主体场景每条镜头各写各的。

中文版（贴即梦/豆包）：
```
〔画幅〕、24fps、胶片颗粒、〔媒介质感〕 | 〔光源方向+光质〕、〔主色调〕低饱和 | 〔美学锚点〕风格
```

English 版（贴 GPT/海外）：
```
〔aspect〕, 24fps, film grain, 〔medium/look〕 | 〔light direction+quality〕, 〔palette〕 | 〔aesthetic anchor〕style
```

### 3. 该风格的专属负面词

从 F-TECH 和 F-STYL 反推这种风格最容易被生成器带偏的方向，给 3-5 个点名式排除项
（例：写实风 → 无塑料皮肤/无 3D 渲染感/无过度磨皮；国风 → 无和风元素/无现代物件）。

## 视频版增量（输入是参考视频时，在七维度外加六维）

| 维度 | 看什么 | 输出 |
|---|---|---|
| F-DYNAMIC 动态 | 主体运动方式、环境动态（风/雨/烟）、动静比 | 动态描述 |
| F-LENS 镜头 | 推/拉/横摇/俯仰/跟拍/固定/航拍/移轨/手持九类 | 运镜词表命中 |
| F-TRANS 转场 | 硬切/叠化/匹配剪/甩镜 | 转场风格 |
| F-TEMPO 时长感 | 单镜平均时长、节奏松紧 | 分镜时长区间建议 |
| F-STYL 风格 | 同图片七维度 | 复用 |
| F-TECH 技术 | AI 生成特征识别、颗粒/帧率感 | 技术特征 |

视频版输出在"画面风格锁"外，追加一行**运镜锁**（L5 段可复用的运镜不变式，默认单一匀速）。

## 使用纪律

- 画面风格锁产出后登记进本项目 03-continuity-bible.md 的"视觉规范"节，全项目共用
- 参考图若有明确人物 → 提醒用户：人物身份锁用 @定妆图绑定，画面风格锁只管
  "画面长什么样"，两者并行不冲突
- 免责一句：反推是基于视觉理解的描述，还原不了原始生成参数，供二次创作用
